Overview

Inspired by the Reinforcement Learning lecture at RWTH Aachen University, I built this project to deepen my practical understanding of the subject.

The agent is trained to optimize traffic signal control at a junction. Instead of a predefined rule-based algorithm, the agent learns through a reward structure using the Deep SARSA algorithm.
